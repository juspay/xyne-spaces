Ticket search in the Kanban board has been simplified and made faster. We replaced the previous popover-based search with a clean search input that filters tickets in real time directly within the board. Search is now integrated into the kanban ticket processing logic (no separate results panel) and matches across title, description, xyneId, merchantId, status, and priority, making ticket discovery more intuitive and responsive.
