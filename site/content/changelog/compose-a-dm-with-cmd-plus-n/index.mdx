Starting a new direct message is now faster with a dedicated Compose DM experience and a global Cmd+N shortcut. Pressing Cmd+N takes you straight to the DM composition view (/chat/search?mode=dm), where you can search and select one or more users, type a message, and send—without stepping through multiple screens.



The new ComposeDmPanel includes existing conversation detection to avoid creating duplicates, and the updated SearchUserV2 component supports multi-select with pill-based selections, keyboard navigation, and a smoother user-picking workflow. The DM creation flow remains consistent across platforms: desktop uses routing for a seamless in-context experience, while mobile continues to use the modal-based pattern.
