You can now message yourself in Xyne Spaces via a new Saved Messages DM—your personal space for notes, links, quick drafts, and anything you want to keep handy. All self-sent messages live in a single dedicated conversation thread, so it’s easy to search and revisit important context later without cluttering team chats.



Saved Messages is designed to stay distraction-free: it shows up as “Saved Messages” in the UI, doesn’t generate notifications, doesn’t add to your unread count, and the conversation preview displays the message content without the “You:” prefix. If you already have a self-DM, Xyne will reuse the existing thread automatically, and you can also forward messages to Saved Messages to quickly archive useful information.
