We’ve added Mark as Read support so you can quickly clear unread messages and keep your inbox state accurate. This is especially useful when you’ve skimmed a thread (or caught up elsewhere) and want your chat list to reflect that you’re already up to speed. Marking a conversation as read updates its unread state immediately, reducing notification noise and helping you stay organized across busy message threads.
