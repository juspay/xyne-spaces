We’ve redesigned the mobile profile menu with a new drawer-based experience for a more native, spacious, and touch-friendly UI. The previous popover has been replaced with a modern drawer (via vaul), making it easier to access profile actions without feeling cramped on smaller screens.



Status management has also been upgraded with dedicated views for setting and editing statuses, including status suggestions to help users update quickly. Profile settings are now more cohesive, bringing profile details, theme selection, and developer settings into a single, streamlined flow. Transitions between views are smoother with framer-motion animations (including height-aware transitions), and status/presence updates are kept in sync in real time through Zero integration.
