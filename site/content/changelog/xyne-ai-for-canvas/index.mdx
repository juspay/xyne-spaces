Xyne Spaces now supports AI-powered canvas workflows, letting you use XyneAI to create and work with canvases through natural language. You can generate structured content in markdown and have it instantly turned into a new canvas, or enable the “Create Canvas” toggle to automatically save AI outputs directly into a freshly created canvas—perfect for PRDs, meeting notes, investigation logs, and structured documentation.



XyneAI can also read canvas content securely using a viewAccessId, allowing the assistant to use existing canvas context while answering questions or generating updates. For ongoing work, you can edit existing canvases through AI with proper access control in place—so updates happen safely within the collaborative editing system rather than being copied around as standalone messages.



In addition, canvases now support selection-based AI interactions: highlight a section of text and ask XyneAI questions using that selection as context. This makes it easy to refine specific paragraphs, rewrite sections, extract action items, or validate details without sending the entire document—bringing faster iteration and deeper collaboration directly into the canvas editing experience.
