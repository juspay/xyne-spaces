---
title: "Ticket Filters: Clear All + Active Filter Indicators"
description: "Filtering in the Kanban view is now easier to manage."
date: "2026-02-11"
---
Filtering in the Kanban view is now easier to manage. We’ve added a “Clear All Filters” action in the filters dropdown so you can instantly reset all applied filters in one click. To make active filters more visible, filter controls now show blue dot indicators when filters are applied (e.g., Assignee, Priority, and More Filters), and individual menu items also reflect active states. Internally, filter counting has been refactored into clearer helper functions to improve maintainability and make future filter additions simpler.
