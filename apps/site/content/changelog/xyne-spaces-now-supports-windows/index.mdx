---
title: "Xyne Spaces Now Supports Windows"
description: "Xyne Spaces is now available on Windows, bringing the full desktop experience to Windows users."
date: "2026-02-27"
---

Xyne Spaces is now available on **Windows**, bringing the full desktop experience to Windows users. You can access the same core workflows—chat, tickets, channels/DMs, and day-to-day collaboration—without relying on a browser-only setup.

This improves adoption across teams that primarily use Windows machines and makes onboarding smoother for new users. With native Windows support, Xyne Spaces becomes more accessible as a default workspace, helping teams stay aligned and productive regardless of their operating system.
