User profiles now include a Recent DMs section that shows shared group DMs between you and the user you’re viewing. This makes it easy to discover existing conversations and jump directly into a relevant group chat without searching. The section loads with proper empty/loading states and displays each shared DM with avatars and a member count badge for quick context.
