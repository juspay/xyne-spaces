We’ve upgraded the mobile chat composer to make writing messages on touch devices faster and less cluttered. The input now supports collapsed and expanded modes: when collapsed, it keeps the UI compact with key actions (attachments, placeholder, send) in a single row; when expanded, it opens a full editor experience for composing longer messages.



To bring mobile closer to desktop parity, we added a new MobileEditorToolbar with rich formatting controls—bold, italic, inline code, links, lists, and blockquotes—along with an improved emoji picker workflow. Attachment handling on mobile has also been streamlined with better preview and management during composition, making it easier to send well-formatted messages without losing screen space.
