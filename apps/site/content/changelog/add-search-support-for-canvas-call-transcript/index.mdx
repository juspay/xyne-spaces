title: "Add search support for canvas, call transcript"
description: "Xyne search has been expanded to include Canvas documents and call transcripts, making it easier to find important context beyond chat messages and tickets."
date: "2026-03-03"
---

Xyne search has been expanded to include Canvas documents and call transcripts, making it easier to find important context beyond chat messages and tickets. Canvases and transcripts are now ingested into Vespa, so they appear in unified search results and can be discovered the same way you search for any other content in Xyne Spaces.



This update adds the full end-to-end pipeline for these new content types: ingestion logic to index canvas and transcript data, and query logic to retrieve and rank them correctly in search. As a result, users can quickly locate meeting discussions, decisions, and documentation stored in canvases or captured via calls—improving discoverability and reducing time spent hunting for past context.
