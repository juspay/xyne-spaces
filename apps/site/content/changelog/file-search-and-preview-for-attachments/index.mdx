We’ve added end-to-end file search to XYNE, enabling users to search across file attachments and preview them directly from the unified search experience. This update extends the backend Vespa search service with a new file document type and transformation pipeline, adds file-type support to search validation and permission-aware query building, and upgrades the UI with attachment filtering, improved result rendering for files, and a file preview modal for quick access to content.
