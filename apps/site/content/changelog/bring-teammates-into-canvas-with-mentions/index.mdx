Canvas documents now support @mentions for both users and groups, bringing the same collaboration workflow you’re used to in chat messages directly into BlockNote-based editors (standard and collaborative). When someone is mentioned, the system extracts mentions from canvas content, creates a dedicated mention activity, and delivers notifications in real time across supported channels—including in-app, push, and Slack.



This update also strengthens collaboration mechanics behind the scenes with proper access control, activity tracking, and automatic viewer access grants for mentioned users so they can open the canvas and jump to the relevant context without friction.
