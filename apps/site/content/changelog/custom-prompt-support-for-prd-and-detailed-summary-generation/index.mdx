We’ve improved document generation by introducing a new modal-based workflow that lets users generate PRDs and detailed summaries using either the standard prompt or custom instructions. The new CreateDocumentModal enables multiple document generations without navigating away, while the PRD and summary generation buttons are now unified to launch the modal instead of triggering direct API calls. On the backend, controllers and services have been updated to accept and process custom prompts, enabling more flexible, tailored outputs based on user-specific requirements.
