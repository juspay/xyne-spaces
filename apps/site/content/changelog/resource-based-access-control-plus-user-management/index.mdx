We’ve introduced a new resource-based access control system that replaces the earlier binary admin vs. non-admin model with granular permissions per resource (such as tickets, analytics, and knowledge base). This enables administrators to follow the principle of least privilege by granting users access only to the areas they need.



The dashboard now includes a dedicated User Management experience to view users and manage their permissions through a streamlined UI. On the backend, new ACL validation and permission mutators enforce resource-level authorization, with Zero integration to keep access changes synchronized in real time. Sidebar navigation and route protection have also been upgraded to respect resource permissions, ensuring sensitive screens are only accessible to authorized users.
